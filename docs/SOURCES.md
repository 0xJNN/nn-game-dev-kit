# Research provenance

Current additions (checked 2026-11-02): `UNREAL.md` links Epic's Linux/editor/automation references;
`MODELS.md` links current official HF model cards, quant repositories, OpenRouter's live model
catalog/routing limits, and OpenCode V2 configuration docs. Exact quant metadata is pinned in
`../models.lock.json`. No model leaderboard placement or local coding quality is claimed from metadata alone.

The follow-up [AI coding review](AI_CODING_RESEARCH.md) collects the checked primary sources for
2026 harness design, OpenCode V2 skills/Code Mode/compaction/permissions, OpenRouter routing/privacy/
quotas/caching, GSQ-RCO and ternary quantization, and model-specific runtime limitations. Public
catalog/cards/config/quant snapshots and offline audit evidence are under
`.studio/research/2026-11-02-roadmap-review/`. All five immutable model pins were reconfirmed;
new candidates are research only, not installed profiles or local benchmark results.

This implementation was written for Novanode. It adapts process ideas; it does not bundle the
creator's code, concepts, third-party game reference images, animation archives, or build kit.
Access to those materials is not assumed to grant redistribution rights.
